Global custom CSS

The CSS in Dashboard > Branding > Custom CSS, used by every user without a theme of their own. Activating a theme below copies its CSS there.

Themes

Previews and user themes show on the normal Jellyfin pages (not the dashboard) after a reload, or within about a minute.

Users

A user's theme replaces the global custom CSS for that user only. Changes are saved straight away.

Theme

Leave empty for a theme with no custom CSS.
